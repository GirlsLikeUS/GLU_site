# Girls Like Us 🎀

A trendy, girlish, pink-themed **"coming soon"** landing page for **Girls Like Us**, a
female wardrobe/fashion brand. Immersive, animated, and written entirely in
wardrobe/fashion language (atelier, fittings, stitches, guestlist).

Built with **Next.js 16 (App Router) + React 19 + Tailwind CSS v4**.

## 📐 Architecture

**See [`CLAUDE.md`](./CLAUDE.md) for the full architecture map** — tech stack, file
layout, how `page.tsx` / `globals.css` are organised, important gotchas, and the
customization points (links, colors, copy, animations). Start there before editing.

> Please keep `CLAUDE.md` up to date whenever you change the code.

## Getting Started

```bash
npm run dev     # dev server → http://localhost:3000
npm run build   # production build (also typechecks — note: `next lint` is removed)
npm run start   # serve the production build
```

Edit the page in `app/page.tsx`; all styling and animations live in `app/globals.css`.
